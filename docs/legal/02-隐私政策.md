## 二、我们收集哪些个人信息

我们遵循**最小必要**原则。完整的逐项说明见同目录下 **《个人信息收集与用途清单》**，此处仅作分类摘要：

| 类别 | 具体信息 | 是否必需 |
|---|---|---|
| 账号信息 | 邮箱、密码哈希（若启用密码）、昵称、头像、个人签名 | 邮箱/昵称必需，其余可选 |
| 身份标识 | 渠道服（大区）、游戏 UID | 渠道服必需；UID 可选、默认不公开 |
| 位置信息 | 你**主动**在地图上选择的标记坐标；你选择的城市（用于天气） | 坐标必需（不放标记可不提供）；城市必需 |
| 内容信息 | 你发布的电波文案、徽章、对本命角色的选择 | 可选 |
| 互动信息 | 轻敲/递伞记录、同伞之交关系、拉黑与举报记录 | 使用对应功能时产生 |
| 设备与日志 | IP 地址、浏览器类型与版本、访问时间、请求路径、错误日志 | 自动产生 |
| 偏好设置 | 界面画风、动效开关、隐私精度设置（存储于浏览器本地） | 可选 |

### 2.1 我们不收集的信息

- 通讯录、短信、通话记录、相册、麦克风、摄像头；
- 身份证号、真实姓名、人脸、指纹等生物识别信息；
- 银行卡、支付账户等金融信息；
- **后台持续定位**（仅在你点击地图选点时记录该点坐标，不会持续追踪你的移动）；
- 剪贴板内容、IMEI/IMSI 等设备唯一标识；
- 你在其他应用中的行为。

### 2.2 位置信息的精度处理

- 默认将坐标**模糊化至约 500 米范围**后再展示与存储（服务端做确定性抖动，保证同一用户结果稳定）。
- 你可以在设置中选择更高精度，或选择「仅城市级」。
- 我们**不会**基于你的坐标做轨迹记录、历史位置回放或行为分析。

### 2.3 公开信息的范围

以下信息**对其他用户可见**：昵称、头像、签名、渠道服徽记、标记位置（按你的精度设置）、徽章、公开的电波。

以下信息**默认不公开**：邮箱、游戏 UID、IP、登录时间、拉黑与举报记录。

## 三、我们如何、为何处理这些信息

| 处理目的 | 涉及信息 | 法律依据（《个人信息保护法》第十三条） |
|---|---|---|
| 注册、登录、找回账号 | 邮箱、密码哈希 | 订立与履行合同所必需（第 2 项） |
| 在地图上展示你与同好 | 昵称、头像、渠道服、坐标、签名 | **你的同意**（第 1 项） |
| 判断"是否同服"、计算附近的人 | 渠道服、坐标、UID 可见性 | **你的同意** |
| 界面天气（按城市） | 城市名称/城市坐标 | **你的同意** |
| 站内互动（敲/递伞/电波） | 互动记录、内容 | 订立与履行合同所必需 + 你的同意 |
| 安全风控、防刷、防攻击、纠纷处理 | IP、UA、日志、举报记录 | 履行法定义务 + 我们的合法利益（第 2、5 项），且不损害你的重大权益 |
| 匿名统计（如在线人数、分布热力） | 聚合后的计数，不含个人标识 | 你的同意（仅用于展示聚合结果，不可反推个人） |
| 依法配合监管或司法机关 | 依要求提供 | 履行法定义务（第 3 项） |

**我们不进行**：个性化广告推送、用户画像售卖、基于敏感信息的自动化决策。站内「同服置顶」仅是按你自选的渠道服做排序，**不对你的权益产生重大影响**。

## 四、敏感个人信息的单独同意

4.1 依据《个人信息保护法》第二十九条，处理敏感个人信息应取得**单独同意**。本服务涉及的敏感个人信息包括：**精确位置信息**、**游戏账号标识（UID）**、**未满 14 周岁用户的个人信息**（本服务不向未满 14 周岁用户开放）。

4.2 因此，注册/登录时会**单独弹窗**征求你对以下事项的同意，且**不得默认勾选**：

- ☐ 我同意在公开地图上展示我选择的位置（默认模糊至约 500 米）
- ☐ 我同意在我主动开启时，向**同服**用户展示我的游戏 UID
- ☐ 我确认我已年满 14 周岁

4.3 你可以拒绝上述任一选项。拒绝位置展示的，仍可浏览地图、使用天气与名片功能，但无法放置标记；拒绝 UID 展示的，不影响其他功能。

4.4 你可以随时在「设置 → 隐私」中撤回上述同意，撤回后我们将停止相应的处理（不影响撤回前已进行的处理的效力）。

## 五、委托处理、共享、转让与公开披露

### 5.1 委托处理（服务商）

我们使用以下服务商协助提供服务，他们会接触为实现功能所必需的信息：

| 服务商类型 | 用途 | 接触的信息 | 说明 |
|---|---|---|---|
| 云服务器 / 数据库服务商 | 托管服务与存储数据 | 全部存储数据 | 服务器位于**中国境内** |
| 对象存储 / CDN | 静态资源分发 | IP、UA | 境内节点 |
| **天地图**（国家地理信息公共服务平台） | 提供地图瓦片 | **IP、UA、瓦片坐标** | 你浏览地图时，浏览器会直接向天地图请求瓦片，天地图会获知你的 IP 与所看区域 |
| **Open-Meteo / 和风天气** | 提供城市天气 | **城市名或城市级坐标**（由我们的服务端代请求，不传你的标记坐标） | 天气请求不携带你的账号信息 |
| 邮件服务商 | 发送验证码与通知 | 邮箱地址 | 境内服务商 |
| 短信服务商（如启用） | 可选的通知渠道 | 手机号（仅在你主动绑定后） | 非必需 |

我们与上述服务商约定其仅可按我们的指示处理信息，并采取必要的安全措施。

### 5.2 共享

除以下情形外，我们**不向任何第三方共享**你的个人信息：

1. 已取得你的**单独同意**；
2. 你主动使用需要共享的功能（例如公开你的电波内容）；
3. 法律法规要求或有权机关依法要求；
4. 为保护你或他人的生命、财产安全所必需。

### 5.3 转让

如发生合并、分立、解散、被收购等情形，我们将告知你接收方的名称与联系方式，并要求接收方继续履行本政策；接收方变更处理目的的，将重新取得你的同意。

### 5.4 公开披露

我们不会公开披露你的邮箱、UID、IP 等非公开信息。**你自行公开的内容（昵称、签名、坐标、电波）属于你主动公开的信息。**

### 5.5 不出境

**你的个人信息存储于中华人民共和国境内，我们不向境外提供。** 若未来确需出境，我们将依法进行安全评估或订立标准合同，并单独取得你的同意。

## 六、存储地点与期限

| 信息类型 | 保存期限 |
|---|---|
| 账号信息（邮箱、昵称等） | 账号存续期间；**注销后 15 日内删除或匿名化** |
| 标记坐标与内容 | 同上；你收回标记后立即停止展示，并随账号注销删除 |
| 互动记录（敲/递伞） | 账号存续期间；注销后删除 |
| 举报与处理记录 | 处理完毕后 1 年（用于申诉与重复违规判定） |
| 访问日志（IP、UA、时间） | **不少于 6 个月**（《网络安全法》第二十一条要求），到期删除 |
| 同意记录（consent log） | 账号存续期间 + 注销后 3 年（用于证明我们已取得同意） |

**超期处理**：保存期限届满或你注销账号后，我们将删除或匿名化处理，法律另有规定的除外。

## 七、我们如何保护这些信息

7.1 **技术措施**：全站 HTTPS；密码以 scrypt 加盐哈希存储（不可逆）；会话采用 HttpOnly + SameSite Cookie；数据库仅内网访问；坐标与 UID 分表/分权限访问；对批量查询与导出做限流。

7.2 **管理措施**：最小权限原则，仅运营者本人可访问生产数据；定期备份并验证可恢复性；关键操作留痕。

7.3 **安全事件**：若发生个人信息泄露、篡改、丢失，我们将立即启动应急预案，**在 3 个工作日内**通过站内公告与邮件告知受影响的用户，并向主管部门报告。

7.4 **风险提示**：任何系统都无法保证绝对安全。请勿在公开内容中填写你的真实姓名、住址、联系方式。
