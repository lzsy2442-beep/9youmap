# 舟友地图（zhoupmap.com）拆解 & 《重返未来：1999》版「9友地图」实现方案 v3

> 调研：2026-11-19
> v2 修订：删「同一把伞下」房间；登录即选渠道服；克隆体→金兔子；界面天气跟随城市；荒原视觉
> v3 修订：**仅做国内**（去掉海外服）；**底图改用天地图/标准地图，版图必须正确**；**所有注册用户都上图**，同服做特别标记；暴雨彩蛋确认要做

## 一、事实与规模

| 项目 | 事实 |
|---|---|
| 站点 | zhoupmap.com（站长自称「舟P地图」，玩家叫「舟友地图」） |
| 作者 | B 站 UP 主「Breeze 青岚」，个人同人项目，与鹰角无官方关系 |
| 玩法 | 世界地图落点 → 选本命干员 / 可选 UID → 看附近同好 → 互相「碰」加好友 → 串门、喊话、一起听歌 |
| 规模 | 报道 13 万注册；实测首页「全球 32 万只舟P · 不算克隆体 14.2 万位」 |

**实测技术栈**（抓 HTML / Next.js 分包 / i18n 包所得，非推测）：

| 层 | 结论 |
|---|---|
| 前端 | Next.js App Router + React + CSS Modules（无 Tailwind、无组件库）+ 自研 i18n |
| 地图 | 高德 JS API 2.0，OSM 兜底，卡通/写实/轻量三档画风 |
| 接口 | 写操作统一 `POST /api/world/:method`，body `{args:[...]}`；另有 `/api/around`、`/api/roaches?since=`、`/api/hot` 等 |
| 实时 | 无 WebSocket：EventSource(`/api/events`) + `since` 游标增量轮询 |
| 部署 | Caddy → Node → 腾讯云香港单机（免备案），月成本 ¥100–200 |

工程细节可抄：`401` / `428`（需重新同意隐私，带 `code`）/ `429`（带 `retry-after`）；公告与灰度挂响应头 `x-notices` / `x-gray`；`/api/around` 同时返回 `near` 与 `far` 聚合。

## 二、核心机制（为什么它有效）

1. **两步式加好友**：偷偷碰（对方只知道被碰了）→ 大胆碰（暴露资料）→ 互相大胆碰才成好友。
2. **本体 + 克隆体**：本体 1 只（24h 限挪 N 次），克隆体可多放、可做客。
3. **不登录也能看到"有多少人"**：计数器吊胃口，登录才解锁人。
4. **彩蛋即认同**：塔露拉篝火、明河都尉轨迹，带来"这站懂我们"。

### 3.2 渠道服：只做国内，全员上图，同服特别标记（v3 定稿）

**事实**：官方公告明确国服分**官方大区**与**渠道大区**——渠道大区包含「华为应用市场、鸿蒙应用商店、小米应用商店、vivo 应用商店、OPPO 应用商店、Bilibili 应用中心、应用宝、4399 游戏中心」；官服 iOS/Android 互通，官服与渠道服、渠道服彼此之间**不互通、不能互加好友**。本版**只做国内**，不接国际服/日服/韩服/台服。

**产品规则（v3 改）**：

| 场景 | 规则 |
|---|---|
| 上图 | **所有注册用户都显示在地图上**，不隐藏、不灰掉跨服 |
| 同服标记 | 同服用**铜金描边 + 小旗徽记 + 悬停优先**；跨服用常规纸色 + 「异服」小字 |
| 附近/雷达 | 默认「全部」，**同服置顶**，再按距离；可切「仅同服」 |
| 递伞（加好友） | **只在同服成立**；跨服返回 `409 SERVER_MISMATCH`，提示「你们不在一个服务器，游戏里加不了好友」 |
| 轻敲伞沿 | **跨服也可**（纯打招呼，不加好友），这样跨服玩家不至于完全无互动 |
| 电波 | 默认同服；可选「全部」，但文案提示跨服收不到好友 |
| 本周伞下 | 默认按服统计，可切全服总榜 |
| UID | 与服绑定，仅同服可复制；只做宽松校验 |

**服务器是配置表，不是硬编码**（官方会新增/合并渠道）：

```sql
servers(id, key, name, short, region ENUM('cn_official','cn_channel'),
        color, sort, is_active, note)
-- 种子：official / bilibili / huawei / harmony / xiaomi / vivo / oppo / tencent / 4399
```
加一个渠道 = 插一行 + 后台勾选，不用发版。

### 3.3 地图与版图合规（v3 新增，红线）

**结论：不能用 OSM 当底图。** OSM 的中国边界画法不符合我国标准，且缺南海诸岛小图；一旦被举报，属于"问题地图"，比性能问题严重得多。

**推荐方案：天地图（国家地理信息公共服务平台）WMTS**

```
矢量底图  https://t{s}.tianditu.gov.cn/vec_w/wmts?...&LAYER=vec&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk=KEY
矢量注记  .../cva_w/wmts?...&LAYER=cva...
影像底图  .../img_w/...   影像注记 .../cia_w/...
s 取 0–7 轮询
```

| 项 | 说明 |
|---|---|
| 申请 | 天地图 API 控制台免费申请 `tk`（个人可申请），有日配额 |
| 坐标系 | **CGCS2000 ≈ WGS-84，无需 GCJ-02 纠偏**（这点比高德省事，高德要纠偏） |
| 版图 | 天地图是审核通过的完整版图（含南海诸岛、九段线），**不需要自己补图** |
| 署名 | 页脚固定 `地图数据 © 天地图 · 审图号 GS(20xx)xxx号`（**以天地图服务页公示的最新审图号为准，照抄，不要自己编**） |
| 备用 | 天地图挂了 → 切换**高德**（同样有审图号，但需做 GCJ-02 纠偏）；再挂 → 纯纸面 + 城市名，绝不回落到境外底图 |

**落点限制**：只允许落在**中国境内（含港澳台）**，境外点击提示「司辰只在这片土地上留伞」。用 GeoJSON 国界做一次点在面内判断，服务端二次校验。

**标准地图的用法**：自然资源部标准地图服务（bzdt.ch.mnr.gov.cn）可免费下载带审图号的 JPG/EPS，适合做**关于页、分享图、海报**这类静态图；交互地图仍用天地图瓦片。两者都须标注审图号。

**资质提醒（说实话）**：面向公众提供地图展示+标注，严格讲属于"互联网地图服务"，需要相应测绘资质。个人同人站通常不具备。可做的缓解是：**用已审核的底图服务、不改边界、显著署名审图号、非商业、可下架**。风险需自行评估；如果站点做大，建议正式咨询或转用有资质服务商的商用条款。

### 3.4 天气系统（跟随城市）

- 注册时选城市（省市二级或搜城市），存 `city_code + lat/lng`；允许授权定位自动填。
- 数据源：MVP 用 **Open-Meteo**（免费无 Key），上线换 **和风天气**（国内更准）。抽象 `WeatherProvider`，换源不动页面。
- **服务端代理 + 缓存 15 分钟**，前端不直连第三方。
- 天气 → 界面：

| 天气 | 表现 |
|---|---|
| 晴/白天 | 暖沙纸面、尘埃粒子 |
| 夜间 | 夜色 + 铜灯暖光 + 星点 |
| 小雨 | 细密雨丝（Canvas，低密度） |
| **暴雨/雷暴** | **全站暴雨预警**：雨幕加厚、地图去饱和、金兔子消失又出现、顶部横幅 |
| 雾 | 视差雾层 |
| 雪 | 雪粒子 + 冷色偏移 |
| 高温/大风 | 热浪抖动 / 旗帜飘动 |

- 性能：`prefers-reduced-motion` + 设置项「减少动态效果」，移动端默认低密度。
- **彩蛋（确认要做）**：你所在城市正在下暴雨时，文案换成司辰语气——「这场雨，是从哪一年下过来的？」；并弹出「暴雨预警 · 请确认你的时代」。

### 3.5 视觉：荒原

设计令牌（直接落 CSS 变量）：

```
--paper #EFE4CC  --paper-deep #E3D4B4  --ink #2C2419
--brass #B08A4F  --brass-lt #D8B77A   --moss #3E4A38
--rust  #8C3B2B  --fog #C9C2AE
```

- **形状**：纸片卡（1px 内描边、四角微装饰、薄阴影），不用大圆角玻璃拟态。
- **线**：双线细描仿版画；分隔线用铜色虚线 + 小菱形。
- **字**：思源宋体，标题 600 / 正文 300；计数器 `tabular-nums`。
- **纹理**：全局纸纹（SVG feTurbulence 噪点 base64，一次性），地图上叠 8% 纸纹。
- **地图滤镜**：`sepia(.3) saturate(.85) contrast(.95) brightness(1.02)`；瓦片不染色，只加整体滤镜。
- **图标**：手绘线稿，1.5px 描边圆头；状态色只用铜金/锈红/墨绿。
- **动效**：200–320ms ease-out，纸页翻动、铜齿轮微转。
- **隐喻**：左侧「孤屿」= 功能导航，罗盘 = 雷达，图钉 = 我的伞，手提箱 = 个人中心。

### 3.6 差异化彩蛋

1. 暴雨预警（真实天气驱动）。
2. 时代滤镜：底图配色切 1966 伦敦 / 1926 美国（CSS filter，零成本）。
3. 考据层：现实地点 ↔ 剧情舞台对照。
4. 维尔汀的手提箱：隐藏点位 → 个人名片。
5. 荒原孤屿：徽章 → 荒原建筑摆放（轻度养成）。

## 四、技术选型

```
浏览器 ── Next.js (App Router) ── Route Handlers ── SQLite(better-sqlite3)
                                   ├─ SSE /api/stream
                                   ├─ 天气代理（Open-Meteo → 缓存 15min）
                                   ├─ 天地图 tk 服务端保管（前端只拿到受限参数）
                                   └─ 定时任务（周榜、过期清理、天气预热）
```

- **地图**：Leaflet + 天地图 WMTS（WGS-84，无纠偏）。`MapProvider` 抽象，换高德只改实现。
- **数据层**：`better-sqlite3` → 上线换 Postgres 只改 repository。
- **附近查询**：`geohash` 5 位（≈5km）粗筛 + 距离精算；首屏只画聚合点。
- **接口风格**：薄 REST，统一 `{ok, data, error:{code,message}}`，`429 + retry-after`。

## 六、接口

```
GET  /api/servers                       → 国内服务器（分组、颜色、是否可用）
POST /api/auth/signup   {email, serverKey, cityCode}
POST /api/auth/verify   {email, code}

GET  /api/map/me
POST /api/map/place     {lng,lat,kind}  → 撑伞 / 放金兔子（境内校验 + 限流）
POST /api/map/move      {markerId,lng,lat}
GET  /api/map/feed?since=
GET  /api/map/around?lng&lat&server=all|mine   → {near, far}，同服置顶

POST /api/touch         {markerId,kind} → knock 跨服可；give 跨服 409 SERVER_MISMATCH
POST /api/shout         {text,radius,scope}
GET  /api/radar?lng&lat&r=&server=
GET  /api/hot?board=&server=

GET  /api/weather?cityCode=
GET  /api/stream
GET  /api/me
```

错误码：`401` 未登录 · `403` 黑名单 · `409 SERVER_MISMATCH` 跨服 · `422 OUT_OF_CHINA` 境外落点 · `429` 限流。

## 八、合规清单

> 法律文本与登录同意流程已单独落地：[docs/legal/](legal/README.md)（用户协议 / 隐私政策 / 个人信息收集与用途清单 / 免责声明 / 社区规范 + 实现规格）。

1. **版图**：天地图/高德底图 + 页脚审图号；禁止 OSM 等境外底图；禁止自绘边界。
2. **落点**：仅中国境内（含港澳台），服务端二次校验。
3. **非官方声明**：首页常驻「非官方同人项目 · 与深蓝互动无关 · 联系与举报」。
4. **个人信息**：UID 默认不公开、位置默认城市级、可收回、可注销。
5. **天气数据**：遵守 Open-Meteo（CC-BY）与和风天气许可，页脚署名。
6. **素材**：一起听只放官方公开试听或外链；立绘非商用。
7. **未成年人**：年龄校验 + 举报通道。
8. **防刷**：新号 24h 禁发波、同 IP 限注册、点位接口 ETag + 限速。
