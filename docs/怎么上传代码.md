# 怎么把代码传到 GitHub（不用装 Git）

> 前提：你已经在 GitHub 建好了仓库。如果还没建，先看下面第 0 步。

---

## 第 0 步：先改仓库名（重要）

GitHub 的仓库名**只允许 ASCII 字母、数字和 `. - _`**。

你填的 `9友地图` 会被自动截断成 **`9`**（你截图里的绿字提示就是这个意思）。

改法：
1. 打开仓库页面 → **Settings**（设置）
2. 最上方 **Rename** 输入框改成：`jiuyoumap`
3. 点 **Rename**

> 也可以叫 `9youmap` / `jiuyou-map`，只要全是英文字母数字就行。
> 名字只是网址的一部分，不影响站点本身。

---

## 第 1 步：确认要传哪些文件

打开 `E:\9友地图`，**只传这些**：

```
server/       后端（Node）
worker/       Cloudflare Worker 版
public/       前端页面、样式、脚本、图标
scripts/      构建/备份/管理脚本
docs/         文档 + 法务文本 + 截图
deploy/       服务器部署用的 Caddyfile、systemd
package.json
wrangler.jsonc
README.md
.gitignore
.github/      （可选，用 GitHub Actions 部署才需要）
```

**绝对不要传**（这些是本地数据和密钥）：

| 目录 | 里面有什么 | 后果 |
|---|---|---|
| `data/` | 数据库、`session.key`、`local.json`（含天地图 Key） | **Key 泄露，别人能刷你的配额** |
| `backups/` | 数据库备份 | 数据泄露 |
| `out/` | 我调试时的截图（29MB） | 仓库变胖 |
| `scripts/.cache/` | 抓取缓存 | 无用 |

> `.gitignore` 里已经排除了这些，但**网页上传不会读 `.gitignore`**——网页上传是"你拖什么就传什么"，所以必须自己注意别拖进去。

---

## 第 2 步：上传（方法 A：网页拖拽，推荐）

1. 打开你的仓库主页；
2. 点 **Add file → Upload files**（添加文件 → 上传文件）；
3. 打开 Windows 资源管理器，进入 `E:\9友地图`；
4. **选中这 10 项**（`server` `worker` `public` `scripts` `docs` `deploy` `package.json` `wrangler.jsonc` `README.md` `.gitignore`），直接拖进浏览器中间的虚线框；
5. 等进度条走完（约 1MB，几秒）；
6. 往下滚，**Commit changes** 区域填一句 `init`，点绿色按钮提交。

> **一次拖不完怎么办**：GitHub 单次最多 100 个文件。你这里一共 65 个，一次就够。
> 如果哪个文件夹没传上，再点一次 Upload files 单独补传即可。

### 传完检查这几项

- [ ] 仓库根目录能看到 `package.json`、`wrangler.jsonc`、`README.md`
- [ ] `server/`、`worker/`、`public/` 三个文件夹都在
- [ ] **没有** `data/`、`backups/`、`out/`
- [ ] 能看到 `.gitignore`（如果没传上，见下面"补传隐藏文件"）

### 补传 `.gitignore` / `.github`

Windows 资源管理器默认**不显示以点开头的文件**，可能拖不到。两个办法：

**办法一：显示隐藏文件**
资源管理器 → 顶部 **查看** → 勾选 **隐藏的项目**，再拖 `.gitignore`。

**办法二：网页新建**
仓库 → **Add file → Create new file** → 文件名填 `.gitignore` → 把本地 `E:\9友地图\.gitignore` 的内容粘进去 → 提交。

`.github/workflows/deploy.yml` 同理（这个只有你想用 GitHub Actions 自动部署才需要；用 Cloudflare「Connect to Git」的话可以不传）。

---

## 第 3 步：告诉 Cloudflare 去读它

回到 [docs/最省心上线.md](最省心上线.md) 的第 3 步：

Cloudflare → **Workers & Pages → Create → Workers → Connect to Git** → 选你这个仓库。

GitHub 会弹窗要授权，点 **Authorize**（只读权限就够）。如果仓库是 Private，记得在弹窗里勾选它。

---

## 方法 B：GitHub Desktop（要装软件，但更省心）

如果你嫌网页上传麻烦，装个 GitHub Desktop：

1. https://desktop.github.com 下载安装；
2. 登录 GitHub 账号；
3. **File → Add local repository** → 选 `E:\9友地图`；
   - 如果提示"不是 Git 仓库"，点 **create a repository**，路径填 `E:\9友地图`；
4. 左下角填提交说明，点 **Commit to main**；
5. 点右上角 **Publish repository**，仓库名填 `jiuyoumap`，**取消勾选 "Keep this code private"** 或保持勾选都行。

以后改代码就三步：改文件 → Commit → Push。

---

## 方法 C：命令行（你已经装了 Git 的话）

```bash
cd E:\9友地图
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/<你的用户名>/jiuyoumap.git
git push -u origin main
```

`.gitignore` 会自动排除 `data/` 等目录。

## 常见问题

**拖拽没反应**
换个浏览器（Chrome / Edge），或者用方法 B。

**上传了一半报错**
GitHub 网页上传对 100 个文件、单文件 25MB 有限制。你的文件都很小，基本不会遇到；真遇到就分批拖。

**传错了文件（比如 data/）怎么办**
在仓库里点进那个文件 → 右上角 **删除（垃圾桶图标）** → 提交。
如果 `local.json` 已经推上去过，**立刻去天地图控制台重置 Key**——Git 历史里还能翻到。

**仓库是 Public，代码被人看到没关系吗？**
开源同人项目通常无所谓，但要注意：`data/` 里的密钥绝对不能进仓库；另外法律文本里的联系邮箱会公开。

**以后想改代码**
- 网页改：点文件右上角铅笔图标 → 改 → 提交，Cloudflare 两分钟自动生效
- 本地改：装 GitHub Desktop，Commit + Push
