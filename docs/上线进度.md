## 回来后的两条路

### A. 绑自己的域名（便宜、10 分钟验证）

1. 买域名（¥10–30/年的 .top/.xyz 也行）
2. Cloudflare → Add a site → 选 Free → 按提示改 NS
3. Workers → 9youmap → Settings → Domains & Routes → Add → Custom domain
4. **手机 4G 再测一次**
   - 能开 → 免费方案继续用
   - 打不开 → 走 B

### B. 迁到国内云主机（稳，但要备案）

- 腾讯云/阿里云轻量 2C2G（新用户首年约 ¥99，学生机 ¥9–10/月）
- 个人 ICP 备案 7–20 天
- 部署 `server/` 的 Node 版（比 Worker 版多实时推送）
- 步骤见 [部署上线.md](部署上线.md)，配置文件在 `deploy/`
